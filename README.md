# 📱 Mobile Sales Data Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Mobile Sales Data Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a comprehensive view of mobile sales performance and allows users to analyze sales based on mobile models, brands, payment methods, cities, months, customer ratings, and day names.

The main goal of this project is to transform raw mobile sales data into meaningful business insights through interactive visualizations and KPIs.

---

## 🎯 Project Objective

The objective of this project is to:

* Analyze overall mobile sales performance
* Track total sales, quantity, and transactions
* Identify top-performing mobile models and brands
* Analyze sales trends across different months
* Understand customer ratings
* Analyze preferred payment methods
* Compare sales across different cities
* Analyze sales performance by day
* Build an interactive and user-friendly Power BI dashboard

## 📌 Key KPIs

The dashboard includes the following key performance indicators:

| KPI            | Description                       |
| -------------- | --------------------------------- |
| Total Sales    | Overall revenue generated         |
| Total Quantity | Total number of mobile units sold |
| Transactions   | Total number of transactions      |
| Average        | Average sales value               |

---

## 📈 Dashboard Features

### 1. Sales by City

A map visualization is used to analyze sales distribution across different cities.

### 2. Quantity by Month

A monthly trend chart shows how the quantity of mobile phones sold changes throughout the year.

### 3. Customer Ratings

The dashboard analyzes the distribution of customer ratings from 1 to 5.

### 4. Payment Method Analysis

Sales transactions are analyzed based on different payment methods such as:

* Credit Card
* UPI
* Cash
* Debit Card

### 5. Mobile Model Analysis

The dashboard compares sales performance across different mobile models.

### 6. Brand Analysis

A table provides a comparison of:

* Total Sales
* Total Quantity
* Transactions

across different mobile brands.

### 7. Day-wise Sales Analysis

The dashboard analyzes total sales based on the day of the week.
